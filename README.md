# SnapClass

SnapClass is a Python project. Its application entry point and usage instructions will be added as the project takes shape.

## Setup

Create and activate a virtual environment, then install the dependencies:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Keep credentials in a local `.env` file. Do not commit secrets.
